# Собственные костюмы

Загрузи сюда свои `pp.rbxmx` и `Boba.rbxmx` через **Add file → Upload files**.
Можно загрузить один костюм или использовать бинарный `.rbxm` вместо `.rbxmx`.
Для каждого костюма нужен только один исходник, включая другие имена слота. Корень внутри файла должен иметь
то же имя: `pp` либо `Boba`; имена автоматически не меняются.

После Commit changes GitHub Actions подготовит модели и обновит готовые пакеты.
Дождись зелёной отметки **Import own costumes**, затем перезапусти loader.
Исходные загруженные файлы остаются здесь. Модели не помещаются в серверный place.

Gender выбирает модель: Male → pp, Female/Fembxy → Boba.
Полная инструкция о составе модели и креплениях: [custom-outfits.md](../../docs/custom-outfits.md).

Прежнее `boba` и имена `LowerRig`/`TorsoRig` тоже поддерживаются. Имена внутри моделей сохраняются.
