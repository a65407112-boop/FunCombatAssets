# Client RBXM bundle

The authoritative rebuild no longer executes gameplay code from GitHub. The binary client RBXM bundle is generated directly from the rebuilt place and contains StarterGui, StarterPlayer, native KeyframeSequence animation packs, VFX, sounds, weather, rig, morph and world asset packs.

Expected bundle filename: `FunCombat_Client_RBXM_For_GitHub.zip`.

Use `manifest.json` for exact filenames, instance counts and SHA-256 hashes. Server RBXM/source is intentionally not part of the public asset repository.
