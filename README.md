# FunCombat — сервер и внешний клиент

Проект собран из `FunCombat_Renamed2.rbxl` с SHA-256 `a14ab714b5b3233a8e05fc5567ce1b9a7dc700ced2ccb2e13771c025f64142b0`. Исходный файл builder не изменяет. Геометрия и визуальное сходство не проверяются по просьбе владельца.

Серверный файл: **funcombat_server.rbxl**, также доступен **Game_Server.rbxlx**. Сервер определяет попадания, урон, cooldown, падение, восстановление, перенос, исполнения, парные взаимодействия, шкалу, Completions, голосование, погоду и общие результаты действий.

Внешний пакет содержит шесть исходных оружий, 47 исходных KeyframeSequence, оригинальные LowerRig/TorsoRig, интерфейсы, звуки, эффекты и ссылки на Roblox-контент. JSON восстанавливает Instances, свойства и внутренние ссылки. Встроенные CSG костюмов загружаются из оригинальных `.rbxmx` через файловые возможности executor и GetObjects. Это обязательная возможность для полного запуска этого пакета; ошибки deserialization именуют конкретный ресурс.

`loader.lua` получает manifest/config/modules по raw GitHub URL, проверяет protocol **4** и точный build ID, соблюдает зависимости, восстанавливает состояние и обрабатывает повторный запуск. Настройки владельца, репозитория и ветки находятся только в начале loader.

Roblox Studio, движок, executor и старый клиент в среде сборки отсутствуют. Офлайн-проверки не подтверждают игровой запуск, сетевую физику, разрешения на hosted assets или совместимость конкретного executor. Adonis/Kohl’s Admin требуют внешних Roblox-модулей; их исходники и настройки сохранены в `source/external`, автоматическое включение не выполнено.
