# Исправление Model.PrimaryPart

Ошибка Studio `Expected BasePart got Workspace for Model.PrimaryPart` возникала
у новой комнаты ожидания. В XML у неё отсутствовало поле `PrimaryPart`;
конвертер записал ссылку на объект 0 (`Workspace`) вместо пустой ссылки.

В текущем `server/funcombat_server.rbxl` исправлена только эта ссылка на `null`.
Каждый другой бинарный блок, включая геометрию, имена, скрипты и флаги служб,
сохранён побайтово. BuildId не изменён.

Сборщики теперь явно заполняют пропущенные ссылки одного класса значением
`null`, сохраняя существующие цели. После конвертации и перед публикацией
проверяется тип каждой сохранённой ссылки по схеме классов Studio.

Проверены все 5 850 ссылок, 48 корневых служб и шесть числовых свойств,
восстановленных ранее. Результаты: [Native_Reference_Checks.json](../Native_Reference_Checks.json).
Запуск в настоящем Roblox Studio здесь не проверялся; публикация в Roblox
этим исправлением не выполнялась. Для проверки скачайте обновлённый RBXL.
