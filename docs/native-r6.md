# Стандартные блочные R6-персонажи

В плейсе нет StarterCharacter. StarterPlayer включает обычную внешность и
Dynamic Heads, задаёт R6, отключает Avatar Unification и переход на новые
AnimationConstraint-joints: исходный бой использует Motor6D.

Server Avatar.prepare не вызывает GetHumanoidDescriptionFromUserId,
ApplyDescription или ручную замену головы игрока. Он удаляет только CharacterMesh
для туловища/конечностей. Head-пакеты, MeshPart-голова, FaceControls, facial Bones,
SurfaceAppearance, одежда, аксессуары и цвета остаются у текущего персонажа.
Поздно добавленные body-пакеты также удаляются сервером.

Смена всего Player.Character проходит обычный CharacterAdded. При замене частей
существующего R6-морфа бой временно закрывается, прежние взаимодействия
освобождаются, затем заново привязываются Humanoid, части и один комплект
промптов. Сохраняются оружие, cooldown и базовая скорость; повторного телепорта
на spawn нет. Неполный морф не получает право на боевые действия. Бой ожидает все семь
R6-частей и Humanoid; смена морфа освобождает также wall-bounce anchor/timer.

Native Animate и его facial/morph tracks остаются у владельца. Старый
locomotion fallback используется только если такого контроллера нет. Исходные
боевые позы продолжают применяться после Animator.

NPC: InitialDummy и DummyRig сохранены в ServerStorage под закодированными
именами. RigFactory.clone восстанавливает engine-имена частей/суставов и
attachments на клоне до его использования. Команда dummy с явным UserId может
загрузить внешность именно запрошенного NPC; эта операция не применяется к
игрокам. Установка головы такого NPC сохраняет прежние ограниченные ожидания.

Внешний client/labels.lua локально восстанавливает objectNames из
config/identifiers.json после подключения сети. Server aliases остаются
согласованными между клиентами. Поздняя репликация обрабатывается через
DescendantAdded; выгрузка возвращает aliases, не перезаписывая имя, которое
после загрузки изменил другой скрипт. Обработка промптов и диагностика понимают
оба варианта имён.

Речь о совместимых R6-морфах. Боевая система не содержит R15-retargeting.
API-проверки не доказывают отрисовку конкретной dynamic head в Roblox.
