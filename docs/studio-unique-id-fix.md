# Исправление duplicate Unique ids

Studio отклонял RBXL с сообщением `DM contains duplicate Unique ids`.
Копия исходной Configuration и её BoolValue сохранила те же UniqueId, что
оригиналы. У новых объектов также оставались нулевые или отсутствующие ID
после преобразования XML в бинарный плейс.

Финальная стадия всех четырёх сборщиков теперь проверяет ID по всему плейсу.
Первая корректная ненулевая запись сохраняется; повторные, нулевые и
отсутствующие значения получают новые неповторяющиеся ID. Публикация также
отклоняет файл с такими ошибками до обращения к Roblox API.

В этой копии назначены 133 ID: 95 вместо нулей, 2 вместо повторов и 36 вместо
отсутствующих. Все остальные бинарные блоки сохранены побайтово, включая
HistoryId, геометрию, имена и скрипты. BuildId и клиентский протокол прежние.

Результаты: [Unique_Id_Checks.json](../Unique_Id_Checks.json). Проверка формата
и декодирование сторонним инструментом не заменяют запуск в Roblox Studio.
Сам Roblox Studio здесь недоступен; публикация игры не выполнялась.

Описание нативной записи UniqueId:
[rbxfile values.go](https://github.com/RobloxAPI/rbxfile/blob/master/rbxl/values.go)
и [arrays.go](https://github.com/RobloxAPI/rbxfile/blob/master/rbxl/arrays.go).
