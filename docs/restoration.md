# Восстановление обычных компонентов — 2026-09-27

Это конкретное дополнение к ранее собранной версии, а не заявление, что всё
исключённое содержимое возвращено. Исходный `.rbxl` не менялся. Имена
возвращаемых объектов и их исходные подписи сохраняются.

| Возвращено | Источник | Поведение |
| --- | --- | --- |
| Gender | StarterGui/Gender, ID 7014 | Исходное окно, кнопки Male/Female/Fembxy, оформление и hover-анимация |
| Info | AttributeSystem/Info, ID 78231 | Исходная надпись над персонажем: DisplayName и подтверждённый выбор, исходные цвета |
| Hover / Click | ID 7041 / 7042 | Исходные SoundId и свойства звуков меню |
| Стандартные эмоции | Animate, ID 6815 | wave, point, dance1/2/3, laugh, cheer; 13 исходных AnimationId, команды /e и /emote |
| Admin | AdminPanel/Admin, ID 78243 | Исходное окно, профиль, вкладки, RIX, перетаскивание, команды Kick/Kill/NoRespawn |
| BillboardGui | ServerStorage/BillboardGui, ID 78369 | Исходная метка OWNER с чёрным текстом для DeluxeyThaLux |

Gender теперь отделён от исключённой механики. Сервер принимает только три
исходных значения для отправителя запроса. Выбор сохраняется в текущей сессии,
после возрождения и в снимках состояния для подключившихся игроков. До
подтверждения сервера окно не закрывается. Другие игроки с внешним клиентом
видят исходный Info. Клиент не может назначить произвольную подпись или
поменять выбор другого игрока.

Стандартные эмоции запрашиваются по имени, без произвольного asset ID. Сервер
проверяет состояние и выбирает один исходный вариант; клиенты получают его
ключ и время начала. Движение, бой и другие авторитетные прерывания отменяют
эмоцию. Завершённая одиночная эмоция не запускается повторно из старого снимка.
В исходном Animate варианты выбирались локально; здесь вариант танца фиксируется
на один запрос для одинакового отображения на подключённых клиентах.

Исправлена ошибка переноски: carryGrabber содержит позу рук и корпуса, но
контроллер ошибочно останавливал вместе с ней ходьбу. Теперь ноги продолжают
использовать исходную анимацию ходьбы. После drop и других снятых ограничений
ходьба восстанавливается по фактической горизонтальной скорости, даже без
нового события Humanoid.Running. Поза переносимого персонажа остаётся отдельной.

В Admin сохранён исходный список доступа: GuardianWorld, ghuisehgfrshdsrgsdd,
Roblox_ovovo. GitHub-аккаунт не назначается администратором автоматически.
Сервер проверяет каждую команду, даже если клиент самостоятельно покажет панель.
Пустой или неоднозначный префикс имени отклоняется. NoRespawn удаляет персонажа
и не позволяет создать нового до выхода игрока из сервера. Это явное усиление
исходной команды, которая только удаляла текущую модель. OWNER — отдельная
исходная метка для DeluxeyThaLux, она не предоставляет административных прав.

Исправлена ошибка предыдущей сборки: Main.server.lua требовал протокол 2,
хотя сервер и клиент уже использовали 3. Стартовый скрипт и snapshot теперь
сравниваются с одной серверной константой, а тест читает версию из настоящего
config/protocol.json. Нужно заменить и предыдущий сервер с протоколом 3.

NewMorphs, NewChanger и связанная ветвь явных сексуальных взаимодействий
остаются исключены. Неиспользуемые авторские риги и сторонние административные
загрузчики также не добавлялись. Полный список отличий — Changes_For_Review.md
в полном архиве. Это не полная копия всех функций исходника.

Требуется обновлённый сервер **protocol 3**. Проверки выполняются на реальных
модулях и исходных данных через rbxmk с заменами недоступных сервисов движка.
Они проверяют код, структуру, имена, свойства, ограничения запросов и очистку.
Roblox, реальная репликация, визуальная работа анимаций и доступность внешних
asset ID здесь не проверены.
