# Исправление пустого плейса в Studio

В прежнем RBXL все 48 корневых служб, включая Workspace и ServerScriptService,
имели сброшенный флаг IsService в бинарных INST-записях. Наличие объектов и
правильных свойств внутри XML не проверяло этот отдельный признак формата.

Это исправление восстановило флаги всех 48 служб. Заголовок и каждый другой
бинарный блок сохранены побайтово; карта, комната, скрипты и морфы не менялись.
BuildId остаётся прежним: клиентский протокол этим исправлением не меняется.

Все пути сборки плейса теперь восстанавливают флаги после XML-конвертации.
Модели, загружаемые клиентом, продолжают сохраняться обычными объектами.
Публикация проверяет корневые службы до обращения к Roblox API.

Подробные результаты: [Place_Service_Checks.json](../Place_Service_Checks.json).
Исправленная копия отдельно ещё не запускалась в настоящем Roblox Studio.
Следующая ошибка `Model.PrimaryPart` исправлена отдельно:
[проверка ссылок](studio-reference-fix.md).

Справка о сохранении статуса служб при конвертации:
[rbxmk v0.9.1](https://github.com/Anaminus/rbxmk/releases/tag/v0.9.1).
